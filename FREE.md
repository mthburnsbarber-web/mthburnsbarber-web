# Free Public Resources

These are public, free-to-use tools and templates from Michael Barber and Black
Label Tech.

## Utilities

- [Discoverability Evidence Kit](https://github.com/mthburnsbarber-web/blacklabel-discoverability-evidence-kit)
  validates public organization facts, evidence claims, and AI-search prompt
  panels.
- [Brand Leak Guard](https://github.com/mthburnsbarber-web/brand-leak-guard)
  fails a deploy when a built site mentions a brand it should not.
- [CDHash Verify](https://github.com/mthburnsbarber-web/cdhash-verify)
  compares the running macOS app to the candidate artifact you built.
- [DKIM Doctor](https://github.com/mthburnsbarber-web/dkim-doctor)
  checks SPF, DKIM, and DMARC DNS health for sending domains.
- [Worker Version Verify](https://github.com/mthburnsbarber-web/worker-version-verify)
  proves the Cloudflare Worker version you are about to deploy matches what
  you meant to build: code byte for byte, bindings, and settings.
- [Worker Version Pull](https://github.com/mthburnsbarber-web/worker-version-pull)
  downloads any Cloudflare Worker version as a folder that `wrangler versions
  upload` sends back byte for byte, so a release changes only what you meant.
- [Polite Fetch](https://github.com/mthburnsbarber-web/polite-fetch)
  fetches the web like a guest for crawlers and AI agents: robots.txt,
  per-host pacing, shared-infrastructure queues, and back-off on challenges.
- [Brand From URL](https://github.com/mthburnsbarber-web/brand-from-url)
  reads an organization's colors, logo, hero photo, and fonts from its
  homepage, and flags white logos and blank "photos" before they ship.
- [ConMon Kit](https://github.com/mthburnsbarber-web/conmon-kit)
  runs the monthly FedRAMP or GovRAMP scans with free scanners and writes the
  raw results, a summary report, and a POA&M that keeps IDs and deadlines.
